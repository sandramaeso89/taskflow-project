# Backend API - conceptos clave

## Axios
Axios es una libreria HTTP para JavaScript que simplifica peticiones (`GET`, `POST`, etc.) y manejo de errores.

Por que se usa:
- API mas comoda que `fetch` para interceptores y timeouts.
- Manejo de JSON mas directo.
- Muy usada en proyectos React/Vue/Node.

## Postman
Postman es una herramienta para probar APIs sin depender del frontend.

Por que se usa:
- Permite enviar peticiones manuales rapidamente.
- Ayuda a validar codigos HTTP y bodies de error.
- Sirve para crear colecciones de pruebas compartibles.

## Sentry
Sentry es una plataforma de monitoreo de errores en frontend y backend.

Por que se usa:
- Captura excepciones en produccion con contexto.
- Agrupa errores repetidos y prioriza impacto.
- Reduce tiempo de deteccion y correccion.

## Swagger (OpenAPI)
Swagger/OpenAPI es un estandar para documentar APIs de forma estructurada.

Por que se usa:
- Define contrato de API (endpoints, schemas, respuestas).
- Genera documentacion interactiva.
- Facilita colaboracion entre frontend y backend.
